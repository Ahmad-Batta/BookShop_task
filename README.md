
# Bookstore & Reading Club

A web-based community bookstore application built with HTML, CSS, and JavaScript. Users can register their membership, choose a reading genre, and request book reservations.

## Features
- **Member Registration:** Interactive prompts to capture user names and membership types ("student" or "regular") with personalized titles ("Scholar" or "Member")[cite: 2].
- **Book Reservation:** Select book genres (fiction/non-fiction) and reserve specific titles[cite: 2].
- **Console Logging:** Tracks and logs user orders directly to the browser's console[cite: 2].

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)
